## 4주차 반응형 수정

### 확인할 문제
작은 화면에서 메뉴, 기능 카드, 이메일 폼이 좁게 보였다.

### 수정한 내용
- viewfort 메타 태그를 추가했다.
- 콘텐츠에 width 와 max-width를 함께 사용했다.
- 기능 카드 목록을 반응형 Grid로 변경했다.
- 768px 이하에서 메뉴, 카드, 폼을 한 열로 구성했다.

### 확인할 화면 너비

1100px / 769px / 768px / 390px


### 5주차 신청폼의 submit
- 사용자가 훈련소식 신청하기버튼 마우스 클릭 또는 엔터키 입력시
- 이메일 형식을 확인하고 형식에 맞지 않을경우
- "이메일을 입력한뒤 신청해주세요." 문구 출력
- 이메일 형식에 맞게 신청한경우 
- "신청한 이메일 주소"를 출력하고 신청이 완료되었습니다
- 문구 출력 및 신청버튼 비활성화
